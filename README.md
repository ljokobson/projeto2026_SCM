## Escopo do projeto

O AgroConecta é um aplicativo móvel para cooperativas do agronegócio, usado por produtores e pelo time de Operações para gerenciar a produção no campo.

### Funcionalidades previstas
- Registro de lavouras e talhões, com área, cultura e datas de plantio e colheita
- Controle de insumos utilizados em cada safra
- Alertas climáticos para apoiar decisões no campo
- Relatórios de produtividade
- Modo offline, com sincronização automática quando houver conexão

### Equipe e responsabilidades
- Gerente do Projeto: coordena o time, os prazos e o relacionamento com a cooperativa
- Desenvolvimento: aplicativo e API
- Banco de dados e nuvem: infraestrutura e sincronização
